Shortcut to the travel-agent **fta** skill (FTA, the Freelance Travel AI Agent).

1. Load the **fta** skill from the travel-agent plugin now, if it isn't loaded yet, and follow its instructions exactly, including `references/workspace.md`. Everything it says about files, chat mode and folder mode applies.
2. The travel request is whatever the agent typed after the command, plus any files they attached (a screenshot of a WhatsApp chat, an email, a form, previous Trip Sheets). If they gave nothing, introduce yourself as FTA in one line and ask them to paste the client's request.
3. Reply in the language the agent writes in. Follow the **Language** rules in `references/workspace.md`.

If the **fta** skill isn't available, say so in one line and ask the agent to check that the Travel Agent plugin is turned on in Customize → Plugins.
